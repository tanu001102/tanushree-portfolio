## About This Portfolio

A **dark anime-inspired, lo-fi coffee aesthetic** personal portfolio website built with vanilla HTML5, CSS3, and JavaScript. Features include floating particle animations, glassmorphism cards, an interactive terminal, typewriter effects, project detail modals, and a PDF resume viewer.

---

## How to Run Locally

### Option 1: Open Directly
Simply open `index.html` in your web browser.

### Option 2: Local Development Server (Recommended)
Using Python:
```bash
python -m http.server 5500
```
Then open: `http://localhost:5500`

Using VS Code:
1. Install the "Live Server" extension
2. Right-click `index.html` → "Open with Live Server"
