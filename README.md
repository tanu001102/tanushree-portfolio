## 🌌 About This Portfolio

A **dark anime-inspired, lo-fi coffee aesthetic** personal portfolio website built with vanilla HTML5, CSS3, and JavaScript. Features include floating particle animations, glassmorphism cards, an interactive terminal, typewriter effects, project detail modals, and a PDF resume viewer.

## 🚀 How to Run Locally

### Option 1: Open Directly
Simply open `index.html` in your web browser:
```
Double-click index.html
```

### Option 2: Local Development Server (Recommended)
Using Python:
```bash
cd "c:\Users\tanu\Downloads\big vision"
python -m http.server 8000
```
Then open: `http://localhost:8000`

Using VS Code:
1. Install the "Live Server" extension
2. Right-click `index.html` → "Open with Live Server"

Using Node.js:
```bash
npx serve .
```

## 🌐 How to Deploy Online

### GitHub Pages (Free)
1. Create a new GitHub repository
2. Push all portfolio files (`index.html`, `styles.css`, `app.js`, `assets/`)
3. Go to **Settings → Pages → Source: main branch**
4. Your site will be live at `https://yourusername.github.io/repository-name`

### Netlify (Free)
1. Go to [netlify.com](https://netlify.com)
2. Drag and drop the portfolio folder
3. Your site is deployed instantly with a free URL

### Vercel (Free)
1. Go to [vercel.com](https://vercel.com)
2. Import your GitHub repository
3. Deploy with one click

## 📝 To Customize

### Add Your Profile Image
Replace the placeholder in `index.html`:
1. Add your image to the `assets/` folder (e.g., `assets/profile.jpg`)
2. Replace the `.portrait-placeholder` div with:
```html
<img src="assets/profile.jpg" alt="Tanushree C R" class="portrait-img">
```

### Add GitHub Repository URLs
Search for `#` placeholder links in `index.html` and replace with your actual GitHub URLs.

### Update Resume PDF
Replace `assets/Tanushree_CR_Resume.pdf` with your latest resume.
